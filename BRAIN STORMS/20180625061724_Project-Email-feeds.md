# Project: Email feeds
集成对指定的一系列网站的推荐文章进行抓取，然后发邮件。
主要是邮件里查看文章和链接实在太方便了。

项目做到一定程度后，可以实现加一层外衣，变成更现代化的鲜果网，聚合自己定制的feeds。

打算做feed的网站：
- [ ] Reddit
- [ ] 简书
- [ ] SegmentDefault
- [ ] CSDN
- [ ] 知乎
- [ ] 微博
- [ ] 豆瓣
- [ ] 稀土掘金
- [ ] 微信公众号（官方网页版）
- [ ] Facebook
- [ ] Youtube
- [ ] 若干技术博客


最好每日一封，全部放在一封邮件里。


可以进行关键词筛选，热度排名等。

每个网站为一个类，一个py文件。

首先一个新闻网站父类，制定基本爬虫，基本处理，默认输出等。

然后每个子类是一个网站，可以复写具体的抓取规则，展现方式。

类中包括功能：
- [ ] 网页抓取
- [ ] 基本文件结构抓取：title，h1 ，h2 等
- [ ] cookies登录

每个网站的抓取规则最好用json，把cookies，主页url，个人内容页url，xpath存进去。


### 关于众多网站的cookies存储问题
手动复制每个网站确实有点麻烦，且不适合程序员以外的人使用。
最好做个Chrome插件，保存每个网站的cookies然后自动更新本地或远程的数据，以供抓取。
