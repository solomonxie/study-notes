# Project: 不基于历史的推荐系统
@2018-05-14

`#推荐系统 #AI # 机器学习 #machinelearning `

只以用户当前的行为预测他喜欢和需要的产品
这个是针对新用户和不需要登录网站的用户所做的专门推荐系统。
且假设情况很糟糕获取不到任何cookies（未来cookies会越来越难获取到所以需要提前准备方案）

即使没有这些因素，还是可以有很多条件可以用来判断，如：网页跳转路径、鼠标移动轨迹、鼠标在链接上停留时间、滚轮滚动方式等等等等。
利用机器学习，训练机器从分析这些行为细节，来判断这样行为的人更有可能是需要什么样的产品。

其实recaptcha判断对方是否人类的时候，就是用这种方式。
