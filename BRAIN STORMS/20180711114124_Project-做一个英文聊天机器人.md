# Project: 做一个英文聊天机器人
`#AI #Englishstudy`

目前国内几乎没有，连微软好像都没做出来。
主要是利用人工智能，机器学习一类，在微信或任何地方（网页之类，whatever），语音聊天。

发现国内的需求还是挺大的。

就是正常聊天，最起码能互相对话，对话过程中还能对你说的每句话进行评分、建议等等。

这个目前还没有，或者还不成熟，所以做出来还是挺好玩的。

主要涉及研究领域：
- 语音转文字
- NLP （English）理解对话
- 回复对话
- 文字转语音


性格问题：
因为纯粹的根据对方的话进行相关的回复，实在太无聊，而且完全无美感，完全没有对话。
对话是需要有主轴的。也就是说，在话题进行不下去的时候，bot要知道找话题开始聊。
不过如果是这样，就涉及到选择性问题，说白了也就是bot的性格问题。不同的性格，不同的方向性选择。
