# （✘已废除）Project: 建立一个网页版服务器管理面板
> 废除原因：搜了一圈，发现市面上已经很多很多可以满足这个需求的成熟产品了，没必要再做。

就是一个dashboard， 有权直接运行后台shell和命令，但是尽量不接受直接输入命令。

把常用各种服务器操作汇聚成一些按钮，一件完成。然后用美化的方式显示结果。 
其实就相当于网页版的桌面，只是不需要那些没有的东西，且专注于日常管理。

常用功能如下：
- [ ] 关机、重启
- [ ] 添加定时任务
- [ ] 开启摄像头，并显示摄像头网址
- [ ] 启动ss
- [ ] 连接外置存储
- [ ] 拷贝指定文件或目录
- [ ] 


最主要的其实是翻译功能，把每个命令结果翻译成人能读懂的东西。

安全问题不太想考虑，太复杂了。
