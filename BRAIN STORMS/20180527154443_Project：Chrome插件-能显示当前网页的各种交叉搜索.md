# Project：Chrome插件 能显示当前网页的各种交叉搜索
`#chrome #extension`

能根据当前网页的主题、信息，显示像`SimilarWeb`或`WhatRuns`的信息，只不过更专注于娱乐相关。

比如动漫视频网页，插件就能显示出它在豆瓣电影和imdb的得分、简介和链接，甚至是百度云或Neets的视频资源链接。
如果是书，就显示Goodreads和豆瓣图书、亚马逊的链接。

在每次点开插件pop页才开始网页爬虫的话，其实比较慢，应该说非常非常慢，大概小10秒会有了。不合理。
所以必要的话应该建立本地数据库，存一些基本内容先。或是网页一打开，就在背后运行、爬取，而不等点开才运行。
