# Project: 用Jekyll建圣经学习笔记网站

和其它数学站、技术站一样，都是从github issues里面保存静态数据，然后用jekyll生成网站。

圣经站要多一个功能：
根据笔记内容中出现的verses，动态弹出小窗口显示这节经文。

实现起来不会太复杂：jekyll生成之前，就用python预处理markdown文件，把所有经文格式`Gen 23:2-5`都标记出来，用`<tag></tag>`夹起来，或变成链接（地址为当前网页地址，但是加上了#gen-23-2-5这样的标记）。主要方便后期js脚本识别。
生成静态网页后，js脚本设置只要鼠标悬浮在这个经文链接上，就会浮现小窗口显示经文。经文数据从github上公开的圣经原文下载数据，预处理一下，然后尽可能分成多个文件（比如一章一个文件），减少网页负担。
