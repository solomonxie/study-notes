# Project: 开发远程连接硬件

现在软件式的远程限制实在太大，根本没发解决很多问题。
所以想开发个硬件解决这一切的需求。

一个usb hub样子和大小的东西，电脑上的鼠标键盘都可以插在上面，外置优盘等也都可以。然后插在电脑上，然后设备可以连接wifi，接收远程的一切鼠标键盘操作，映射到客户端。
画面上可以让客户端用户用手机视频等任意视频连接给服务端显示，然后就可以达到远程操作，甚至可以重装系统。
重装系统这种东西如果纯软件就不可能达到了。

下面是一些基本功能的实现思路：
- [ ] Stdin,通过hub输出为一般键盘鼠标信号，达到一般输入操作。hub会通过wifi接收远程的操作，转换成客户端的输出。
- [ ] stdout 方法一：客户手动发实时视频，或者像监控摄像头一样一直监视显示器，完全脱离软件输出。
- [ ] stdout 方法二：hub作为视频捕捉卡，插上hdmi线，将主机的视频输出捕捉到，然后传输到远程。视频捕捉卡好处就是，连bios页面都可以捕捉到
- [ ] stdout 音频：接收音频输出，用音频线。
- [ ] 开关机：让用户把主板的电源线插上不太容易。换个思路，如果是台式机，就把hub作为电源中转，主机电源插在hub上，hub可以插一根电源线来插在主机上，这样可以控制关机。如果是笔记本电脑就不容易了
- [ ] 重装系统 方法一：客户端自己插上带系统的u盘，然后远程来操作
- [ ] 重装系统 方法二：hub自带单独的sd卡，可以通过远程随时格式化成任意格式、通过远程实时安装上任意os系统，并作为系统启动盘用来安装系统

硬件组成：
- [ ] 树莓派或智能硬件主板 体积越小越好
- [ ] 视频捕捉卡的硬件配置
- [ ] 鼠标键盘的输出信号配置
- [ ] 电源转换的硬件配置

软件设计：
- [ ] 不用设置专用app，只要生成局域网的网页，在浏览器里输入网址就可以操控和设置。
- [ ] 一开始连接wifi的设置，需要用手机或电脑连接设备自带的wifi，来输入本地wifi的密码。像gopro一样。
- [ ] 连接wifi方法二：可以先把网线插在hub上，这样hub就连上网了，然后立刻发邮件或scp或ssh等任意方式发给远程本地的信息，如自己的局域网ip地址、环境、网速等。远程也可以通过邮件等各种方式把wifi的密码和各种设置发过去，这样hub就能wifi连接了。
- [ ] 连接wifi方法三：hub还能通过树莓派一样在sd卡上存一个wifi设置的文件来达到连接目的。
- [ ] 连接wifi方法四：还可以通过蓝牙或红外达到目的
- [ ] 需要精通鼠标键盘的编程和驱动设计才行，必须要设置成通用的驱动，这样能被大多数机器免安装驱动就能用
