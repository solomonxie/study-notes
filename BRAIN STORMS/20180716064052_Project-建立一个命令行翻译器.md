# Project: 建立一个命令行翻译器

可以是py脚本。对命令行常见命令的翻译、美化，用人类语言解释清楚。

这个非常非常有帮助也有需求。从入门到专业都会喜欢。

架构就是一个小函数，接收参数，然后指派用哪个翻译器来翻译。
针对每个命令都有一个单独的翻译器，即一个py类，单独的文件。
这样做就是非常好扩充、修改。也便于opensource社区补充。就像YouTube-dl一样。YouTube-dl就是每个网站一个文件，这样全世界都能进行扩充各国的网站。

难点在于怎么获取已经执行的命令本身，因为光从结果很难猜出是哪个命令执行的。如果是多个命令一起执行那就更复杂了。
简单的解决方法就是不用pipline，而是直接执行脚本，并把要执行的命令语句当参数传给py脚本，然后在python里执行命令行，就能同时获取到命令和输出了

-exec 需执行的语句
或
-in 执行的语句 -out 输出结果
二选一

第一个是python去执行语句分析结果
第二个是python不执行语句，只根据已给的两个条件基础上进行分析
