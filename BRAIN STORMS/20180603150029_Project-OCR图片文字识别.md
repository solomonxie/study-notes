# Project: OCR图片文字识别

分别用python+tessoract, 百度api、网易api等测试

如果是tessoract的话，自制训练集：
将一些指定的笔记转换生成各种各样的截图，且字体随机切换（什么奇怪的字体都包括），同时背景也随机生成。
然后来训练模型，对比准确度。

图片预处理上，需要解决的有：
- [ ] 图片旋转（画线检测图片中文字倾斜度，然后纠正为正常方向）利用opencv 的minAreaRect() 检测倾斜角度，然后利用pdftk旋转.
- [x] 图片提取（imagemagick or pdfimages）
- [x] 用百度ocr将图片转成带坐标的文字
- [ ] 利用文字和坐标信息，重新生成html或xml或PDF（利用python的ReportLab库)，然后转word文档
