# `Map` (Data structure)

A map is sometimes called an associative array or dictionary. 

![image](2018-11-20T06-11-14_`Map` (Data structure)_files/img_01.png)


## ADT DEFINITION

```py
ADT: <MAP>

    A map stores data in key / value pairs where every key is unique. 
    It is often used for fast look-ups of data. 

DATA:
    - Map []
        - key
        - value

OPERATIONS:

    has(key):

    get(key):

    delete(key):

    setValue(key, value):

    
```
